# Audio credits

All game sounds are trimmed, mono-mixed, normalized and, for the cushion,
layered from the following [Freesound](https://freesound.org/) samples.
No network access is used at runtime; the files ship inside this package and
are served by the Host from the fixed `/dsh-billiards/audio/` allowlist.

| File | Source | Author | License |
| --- | --- | --- | --- |
| `cue.wav` | [SPRTIndor_Billiard Cue Ball Strike 01_KVV AUDIO_FREE](https://freesound.org/people/KVV_Audio/sounds/830221/) | KVV_Audio | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `click.wav` | [billiard ball clack](https://freesound.org/people/Za-Games/sounds/539854/) | Za-Games | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |
| `clickSoft.wav` | [Billiard balls single hit-dry](https://freesound.org/people/juskiddink/sounds/108615/) | juskiddink | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `rail.wav` | [Low Thud](https://freesound.org/people/EtherAudio/sounds/750934/) layered with `clickSoft` | EtherAudio / juskiddink | CC BY 4.0 |
| `pocket.wav` | [B_1 pool ball falling](https://freesound.org/people/Yarmonics/sounds/441857/) | Yarmonics | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) |

Changes: leading/trailing silence removed, mixed to mono, peak-normalized,
fade in/out applied, and the cushion sample layered with a short dry ball
click. The original samples remain available at the links above.
